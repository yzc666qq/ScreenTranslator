# ScreenTranslator

ScreenTranslator 是一个 Windows 桌面悬浮翻译工具。目标是让用户框选屏幕区域，持续识别其中的文字，并在透明置顶窗口中显示译文。

## 当前状态

仓库目前包含可运行的 WPF 产品骨架：

- 透明、无边框、始终置顶的悬浮窗口
- 可拖动窗口和基础状态交互
- 屏幕区域、截图帧、OCR 结果和翻译结果的数据模型
- 截图、OCR、翻译三个可替换的服务接口

OCR、区域捕获和第三方翻译接口尚未接入。界面中的“准备框选”按钮当前只用于演示状态切换。

## 技术栈

- C# / .NET 9
- WPF / XAML
- 计划使用 `Windows.Graphics.Capture` 捕获屏幕区域
- OCR 与翻译提供程序通过接口隔离，便于切换本地或云端实现

## 运行

环境要求：Windows 11、Visual Studio 2022 17.14 或更新版本，以及 .NET 9 SDK。

```powershell
dotnet restore
dotnet build
dotnet run --project src/ScreenTranslator.App
```

## 计划

1. 实现全屏透明框选层和多显示器坐标处理。
2. 接入屏幕区域捕获并排除自身悬浮窗。
3. 接入本地 OCR，增加文字变化检测和节流。
4. 接入可配置的翻译服务，避免在仓库中保存 API 密钥。
5. 增加全局快捷键、设置页、托盘图标和安装包。

## 隐私原则

优先在本地完成截图与 OCR。只有识别出的文字在用户启用云端翻译后才会发送给所选翻译服务；密钥应通过本地用户配置或系统凭据存储管理。
